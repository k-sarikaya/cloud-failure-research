# FC-DQN Archive

This folder preserves the pre-revision FC-DQN workflow, weights, notebooks, checkpoint JSON files, and result logs for historical traceability only.

The revised RESS submission is reproduced from the top-level `code/`, `artifacts/`, and `data/processed/canonical_calibration/` paths; `fc_dqn_archive/` is not part of the authoritative revised benchmark pipeline.
